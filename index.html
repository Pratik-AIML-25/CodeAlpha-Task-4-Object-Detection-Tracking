Real-Time Object Detection & Tracking

A computer vision system using YOLOv8, SORT and DeepSORT for object detection, tracking IDs, trajectories and IN/OUT counting.

View Source Code Explore Project

Project Features

🎯 YOLOv8 Detection

Detects objects in video frames and provides bounding boxes, confidence scores and class IDs.

🆔 Object Tracking

SORT and DeepSORT can assign tracking IDs to detected objects across video frames.

📍 Trajectory Tracking

Motion trails show the movement path of tracked objects.

📊 Object Counting

Tracks active objects and maintains the total number of unique tracked IDs.

↕️ IN / OUT Counting

A horizontal virtual line can be used to count objects entering and leaving an area.

⚡ Performance Monitoring

The system includes FPS and processing performance monitoring.

Technology Stack

Python YOLOv8 OpenCV SORT DeepSORT NumPy SciPy FilterPy

Processing Pipeline

Video Input → OpenCV → YOLOv8 Detection → Bounding Boxes → SORT / DeepSORT → Tracking IDs → Trajectory & Counting → Analytics Overlay
